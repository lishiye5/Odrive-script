# FlyFish FOC 周期内不对称扭矩 — 锁死单关节扑动试验

> **目的**: 验证 FOC 在一个扑动周期内随曲柄角度改变扭矩/电流,能否打破"正反行程推力自相抵消"、提升净推力。

> **操作人员**: (待定)

---

## 1. 试验背景

当前锁死单关节扑动试验(0713)显示:
- 推力天花板 ~0.21N(3-4Hz),之后随频率下降
- 6Hz 瞬时推力峰峰达 4.25N,但均值仅剩 0.12N——正反行程推力大量相互抵消
- 电机仅用 ~48% 额定功率(MN2806 KV400, 44W 额定),负载吃不上去

**核心假设**: 锁死导致正行程(推)和反行程(吸)推力对称,正负抵消。用 FOC 在反行程**降低扭矩/转速**,减少反行程的负推力,可提升净推力。

---

## 2. 试验设置

| 项目 | 内容 |
|------|------|
| 试验对象 | FlyFish 锁死单关节扑动(俯仰关节不参与,舵机锁定在正中) |
| 电机 | T-Motor MN2806 KV400, FOC 矢量控制 |
| 频率范围 | **1–5 Hz,步长 1 Hz**(共 5 个频率点) |
| 每段时长 | **30 秒** |
| 测力 | ATI Net F/T 六维力传感器, 1000 Hz |
| 电机数据 | 记录 `time, iq, vbus, target_vel` (FOC日志) |

### 两种工况(必须跑在同一个 session 里)

| 工况 | 正行程(0–180° 曲柄) | 反行程(180–360° 曲柄) | 说明 |
|------|---------------------|----------------------|------|
| **A 对称(基线)** | iq = 恒定值 | iq = 恒定值(同正行程) | 当前已有 0713 数据就是基线 |
| **B 不对称(优化)** | iq = **1.5 A**(全力) | iq = **0.3 A**(最小维持,不过零) | 见 §3 |

> **扫频顺序: A(对称基线) 1→5Hz → B(不对称优化) 1→5Hz。** 先跑完 A 再跑 B,保证零位/水深/水温一致。

---

## 3. FOC 控制要求

### 工况 A — 对称(同 0713)
反行程和正行程使用相同的 iq 设定值,电机在整个周期内对称输出。

### 工况 B — 不对称(本试验核心)
利用 FOC 编码器提供的**实时曲柄机械角度**(或霍尔/编码器折算的角度),按曲柄位置切换 iq 指令:

```
如果 曲柄角度在  0°–180°(正行程,尾鳍向一侧甩):  iq_target = 1.5 A
如果 曲柄角度在 180°–360°(反行程,尾鳍回程):      iq_target = 0.3 A
```

- **正行程 1.5A**:在当前 0713 实测 iq 均值(~1.3A)基础上略提,确保正行程推力不降。
- **反行程 0.3A**:最小电流维持 FOC**不丢步**(不过零),尾鳍在反行程"滑过去、少怼水"。具体最小值请根据实际机构摩擦测试确定;如果 0.3A 维持不住同步,调高到能维持的最小值。
- **过渡**:正反行程之间的切换可以用简单阶跃,不需要斜坡(30s 稳态段,前几秒过渡不参与分析)。

iq 指令示意:
```
iq [A]
1.5 ┤████████████                           ← 正行程 全力推
    ┤            ████                       ← 反行程 低电流滑过
0.3 ┤
    └────────────────────────────→ 曲柄角度
   0°             180°           360°
```

## 4. 数据采集要求

### 力数据 (ATI)
- 1000 Hz 采样
- 记录全部 6 通道: Fx, Fy, Fz, Tx, Ty, Tz(+时间戳)
- 每个频率段存一个文件,或全部连续记录(注明起始时间和频率切换时刻)
- 文件名建议: `{日期}_{工况A/B}_{频率范围}`

### 电机数据 (FOC 日志)
- 至少 50 Hz 采样频率(最好 ≥100 Hz)
- 记录列: `time, iq, vbus, target_vel`(如果编码器角度也可记录,请添加 `position`)
- 文件名与力数据对应

### 试验记录
手记以下内容:
- 水深
- 静水零位(开机后、电机未启动前的 10 秒基线)
- 每个频率段的起始时间(精确到秒,方便对齐)
- 任何异常(电机异响、丢步、撞击)
